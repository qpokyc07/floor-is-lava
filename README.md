# 🔥 Пол — это лава (AR)

Игра для телефона: камера смотрит на вашу комнату, на полу загорается лава и
безопасные камни, а вы по ним прыгаете. Картинка дублируется на телевизор
обычной трансляцией экрана — то есть то, что видит телевизор, это и есть
«AR-вид» с камеры телефона.

Работает в мобильном браузере как обычная страница. Ничего устанавливать на
телефон не нужно.

---

## Как это устроено

```
телефон на подставке  ──камера──►  MediaPipe Pose  ──►  стопы в кадре
                                                          │
                                              гомография пола (4 угла)
                                                          ▼
                                            координаты стоп на полу, метры
                                                          │
                                        ┌─────────────────┴─────────────────┐
                                        ▼                                   ▼
                              правила игры (плитки)                  отрисовка AR
                                        └─────────────────┬─────────────────┘
                                                          ▼
                                             экран телефона ──трансляция──► ТВ
```

**Почему не WebXR/ARCore.** «Настоящий» AR (WebXR) на iOS в Safari недоступен
вообще, а на Android требует ARCore и умеет только «поставить объект на
плоскость» — но не понимает, где ваши ноги. Для этой игры важнее второе,
поэтому здесь: камера + распознавание позы + ручная разметка пола четырьмя
точками. Работает и на iPhone, и на Android, без установки приложений.

## Запуск

Нужен **https** (или `localhost`): браузеры не дают камеру на `http://192.168…`.

### Android — быстрый старт

1. Откройте адрес игры **в Chrome** и разрешите камеру.
2. Меню Chrome (⋮) → **«Добавить на главный экран»** (или «Установить приложение»).
   Дальше запускайте иконкой: приложение открывается сразу во весь экран
   в горизонтальной ориентации.
3. Нажмите **«Начать»** — телефон сам развернётся в горизонталь и попросит
   разрешение, экран не будет гаснуть во время игры.
4. Трансляция на телевизор: шторка Android → **«Трансляция»** / **Smart View** /
   **Google Home → Трансляция экрана**. Для Chromecast — из Google Home.

### Вариант 1 — быстро посмотреть на компьютере

```bash
node serve.mjs
# открыть http://localhost:8080
```

На ноутбуке с веб-камерой можно сразу проверить разметку и картинку.
Проверка математики: `http://localhost:8080/selftest.html`

### Вариант 2 — с телефона через туннель (самый простой путь)

```bash
node serve.mjs
# в другом окне терминала:
cloudflared tunnel --url http://localhost:8080
#   или:  npx localtunnel --port 8080
```

Туннель выдаст `https://…` — открывайте этот адрес на телефоне.

### Вариант 3 — выложить на хостинг (для постоянного использования)

Папку целиком (кроме `serve.mjs`) можно перетащить на
[Netlify Drop](https://app.netlify.com/drop) или в GitHub Pages — там сразу
https, и адрес останется постоянным. Приложению нужен только интернет при
загрузке (модель распознавания тянется с CDN).

### Вариант 4 — свой https

Положите рядом `cert.pem` и `key.pem` (например, из `mkcert`), сервер сам
поднимет https на порту 8443. Корневой сертификат придётся поставить на телефон.

## Подготовка комнаты

1. **Телефон** — на подставке, полке или штативе, **1,2–1,6 м** от пола,
   наклонён вниз примерно на 30–40°. В кадре должны быть и пол перед вами,
   и вы целиком (хотя бы по колени, лучше — целиком).
2. **Расстояние** до игровой зоны **2–3,5 м**. Дальше — точнее видно ноги.
3. **Свет** включите. Контровой свет (окно за спиной) сильно мешает.
4. **Трансляция**: Android — «Трансляция»/Smart View, iPhone — «Повтор экрана»
   (AirPlay), либо приложение телевизора. Телефон при этом продолжает работать
   камерой.
5. По возможности включите полноэкранный режим (кнопка ⛶ в меню) — тогда
   интерфейс не обрезается браузером.

## Разметка пола

При первом запуске игра просит коснуться четырёх углов площадки **на полу**,
по порядку:

```
   4 ●───────────────● 3      дальние углы (дальше от камеры)
     │               │
     │    площадка   │
     │               │
   1 ●───────────────● 2      ближние углы (со стороны камеры)
              ▲
           камера
```

Порядок: **ближний левый → ближний правый → дальний правый → дальний левый**.

Дальше размер можно подправить кнопками «ш» и «г» — сетка на полу сразу
перестроится. Разметка запоминается в браузере.

## Правила

- Пол — лава. Голубые плиты — камни, на них безопасно.
- Каждые несколько секунд камни тонут и всплывают в другом месте. Перед сменой
  они мигают красным, а новые показываются призрачным контуром — успейте
  перепрыгнуть.
- На лаве можно простоять **0,3 секунды**. Дольше — конец игры.
- Проверяются **обе** стопы: держать одну ногу над лавой не получится.
- В воздухе (в прыжке) лава не жжёт — можно перелетать.
- Счёт — сколько секунд продержались. Рекорд хранится в браузере.

## Если стопы определяются неточно

Внизу на панели разметки есть кнопки **«стопа −/+»** — это вертикальная
поправка точки стопы в пикселях.

| Симптом | Что делать |
|---|---|
| Круги под ногами «сзади» вас, ближе к камере | «стопа −» на 3–6 |
| Круги «впереди», игра убивает на камне | «стопа +» на 3–6 |
| Круг прыгает между плитками на границе | нормально: есть допуск 7 см, можно встать по центру плитки |
| Совсем не видит ноги | отодвиньте камеру, чтобы стопы были в кадре целиком |

Нажмите **D** на клавиатуре (или подключите её к телефону) — включится отладочный
слой: точки скелета и найденные стопы.

## Что уже работает и что ограничено

Работает:

- камера + распознавание позы в реальном времени (MediaPipe Pose, ~25 кадров/с);
- перспективная отрисовка лавы и камней на полу через гомографию;
- определение «стопа на полу / в воздухе» (прыжок не прожигает лаву);
- игровой цикл с усложнением, счёт, рекорд, звук;
- сохранение разметки и настроек.

Ограничения прототипа (честно):

- **точность ±10–20 см.** Одна камера не может идеально восстановить 3D-положение
  стопы: поднятая нога выглядит как «дальняя». Поэтому точка стопы считается по
  пятке/носку и подстраивается кнопкой «стопа». Для дома этого достаточно.
- **нужен интернет** при загрузке (модель ~5 МБ с CDN, кэшируется браузером).
- **камера должна стоять неподвижно.** Если её толкнуть — разметка «съедет»,
  нужно размечать заново.
- на iOS Safari нельзя заблокировать ориентацию из кода — поверните телефон
  руками в горизонталь.

## Файлы

```
index.html          разметка экранов (меню, разметка, HUD, результат)
manifest.webmanifest  установка на главный экран, полный экран, горизонталь
icon.svg            иконка
css/style.css       оформление
js/main.js          состояния приложения, игровой цикл, UI
js/floor.js         гомография пол ↔ кадр (чистая математика)
js/pose.js          обёртка MediaPipe Pose Landmarker
js/feet.js          стопы: «на полу / в воздухе», проекция на пол
js/game.js          правила: плитки, камни, предупреждения, смерть
js/render.js        отрисовка лавы, камней, искр
js/audio.js         звук (синтез на WebAudio, без файлов)
serve.mjs           локальный сервер без зависимостей
selftest.html       автопроверка математики и правил
```

## Куда развивать дальше

1. **Точность.** Второй ракурс (два телефона) или оценка глубины через размер
   стопы — уберёт ручную поправку.
2. **Мультиплеер.** Одна сцена, два игрока, общий пол — сервер на WebSocket.
3. **Настоящий AR.** На Android — WebXR Hit Test, чтобы пол находился сам,
   без четырёх касаний.
4. **Оформление.** Скины плиток, музыка, эффекты попадания.
5. **Нативное приложение**, если понадобится работа в фоне и запись видео.
